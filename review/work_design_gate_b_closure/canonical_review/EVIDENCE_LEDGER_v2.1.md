# 0. SOURCE AUTHORITY

| Code | Authority | Definition |
|---|---|---|
| L1 | PROJECT OWNER CURRENT FACT | User-supplied/currently approved factual correction |
| L2 | PRIMARY EVIDENCE | Contract, certificate, patent, official documentary proof |
| L3 | COMPANY ARCHIVE | IR, company profile, historical official company material |
| L4 | PROJECT / PROPOSAL MATERIAL | Proposal/planning/project document; not completion evidence |
| L5 | INFERENCE | Strategic interpretation; cannot be published as fact without approval |
| L6 | EXTERNAL PUBLIC RECORD | An externally published article, report, or public record that can support project existence, publicly documented activities, site visits, consultations, and project context. It does not automatically prove contractual relationships, government authorization, official institutional status, confirmed investment, or final project approval. |
