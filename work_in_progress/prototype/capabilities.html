CORE 01

인식 기반 인터랙션

사람의 얼굴, 움직임, 위치, 시각 정보를 인식하고 시스템이 실시간으로 반응하도록 설계합니다.

COMPUTER VISION FACE RECOGNITION MOTION TRACKING DETECTION REAL-TIME RESPONSE

  • 인식 대상 정의얼굴·동작·위치 중 무엇을 인식할지 정리합니다.
  • 실시간 응답 설계인식 결과가 이어질 반응을 시나리오로 설계합니다.
  • 운영 환경 연동기존 시스템과 연결되는 지점을 검토합니다.

CORE 02

디지털 환경 구축

사용자가 접속하고, 활동하고, 상호작용할 수 있는 가상공간과 플랫폼을 설계합니다.

VIRTUAL SPACE PLATFORM DIGITAL TWIN REMOTE INTERACTION 3D ENVIRONMENT

  • 공간과 이용 방식사용자가 무엇을 하러 들어오는 공간인지 정리합니다.
  • 참여·커뮤니케이션아바타와 음성·화상·공유 방식을 목적에 맞게 구성합니다.
  • 운영과 확장접속 규모와 이후 확장을 전제로 구조를 잡습니다.

CORE 03

공간 경험 시스템

VR·AR, 시뮬레이터, 대형 미디어, 인터랙티브 콘텐츠를 실제 공간에서 체감할 수 있는 경험으로 구현합니다.

VR / AR SIMULATOR CURVED SCREEN INTERACTIVE CONTENT SPATIAL MEDIA SYSTEM
작업 방식
  • 공간 조건 검토화면 형태와 관람 동선, 시야를 먼저 확인합니다.

  • 현장 구현·조정설치 환경에서 실제로 보이는 상태를 기준으로 맞춥니다.
