# 0. PURPOSE
# 0. 문서 목적

이 문서는 리본소프트 홈페이지가 **어떻게 보여야 하고, 어떻게 움직여야 하며, 어떤 시각적 규칙을 끝까지 유지해야 하는가**를 정의한다.

This document defines **how the Rebornsoft website should look, move, and maintain visual consistency from the hero through the final contact section.**

목표는 Spectrascape의 외형을 복제하는 것이 아니다.

The objective is not to reproduce Spectrascape's visual surface.

목표는 Spectrascape에서 확인되는 다음 수준을 리본소프트의 자료와 정체성에 맞게 재설계하는 것이다.

- Strong positioning
- Image-led communication
- Controlled information density
- Technical credibility
- Editorial hierarchy
- Large spatial rhythm
- Precise motion
- High-quality project presentation
- Consistency from desktop to mobile

# 6. DARK / LIGHT BASE DECISION
# 6. 다크 / 라이트 베이스 결정

## Decision
### **Dark-first, not dark-only**
### **다크 우선, 다크 단일은 아님**

Hero와 주요 프로젝트·Experience 영역은 Dark Canvas를 기본으로 한다.

Company / History / selected proof sections는 Light or Warm-neutral Canvas를 사용할 수 있다.

### Why

완전한 Dark-only 사이트는:
- 기술회사 느낌은 강하지만
- 장시간 읽기 피로도가 높고
- 프로젝트 이미지의 변화가 단조로워질 수 있다.

완전한 Light-only 사이트는:
- 기업 신뢰감은 좋지만
- Spatial / Experience scale이 약해질 수 있다.

따라서 **Dark ↔ Light의 리듬 자체를 페이지 구성 요소로 사용한다.**

# 8. GRADIENT POLICY
# 8. 그라데이션 규칙

Gradient는 “AI 사이트 느낌”을 만드는 장식으로 쓰지 않는다.

### Allowed
- 이미지와 배경의 자연스러운 연결
- Hero visual edge fade
- section transition
- subtle signal glow
- depth separation

### Not allowed
- purple-blue blob
- rainbow mesh gradient
- neon orb
- gradient text headline
- excessive aurora background

### Core rule
**Gradient supports depth. It does not become the design.**

# 17. HERO VISUAL STRATEGY
# 17. Hero 비주얼 전략

Hero는 이번 홈페이지 품질을 결정하는 가장 중요한 요소다.

## PRIMARY STRATEGY
### **Cinematic Interactive Environment Visual**

Project evidence를 억지로 한 장에 섞은 콜라주가 아니라,
`Technology for Interactive Environments`라는 회사 개념을 시각적으로 표현하는 **브랜드용 Representational Visual**을 사용한다.

### Desired qualities
- 실제 공간처럼 느껴지는 scale
- 사람의 존재 또는 인간 scale
- digital layer가 물리 공간과 자연스럽게 연결
- sensing / interaction / light / media의 힌트
- 검은 공간 속 단순 neon effect 금지
- architectural photography 수준의 질감
- 텍스트가 올라갈 충분한 negative space

### Important
Hero Visual은 **특정 실제 프로젝트라고 주장하지 않는다.**

It is a brand representation, not project evidence.

### Preferred easing
`cubic-bezier(0.16, 1, 0.3, 1)`

### Secondary easing
`cubic-bezier(0.22, 1, 0.36, 1)`

# 32. SCROLL MOTION
# 32. 스크롤 모션

### Allowed
- opacity 0 → 1
- translateY 24–48px → 0
- image scale 1.025 → 1
- masked image reveal
- subtle horizontal translation
- very light parallax 3–6%
- sticky capability transition
- progress line

### Avoid
- excessive scroll hijacking
- full-page snap on every section
- spinning 3D objects
- continuous cursor-follow movement
- exaggerated perspective rotation
- repeated letter-by-letter animation

# 33. 텍스트 리빌

- supporting copy 80–140ms delayed
- CTA 120–180ms delayed

- use reveal only once on entering viewport
- avoid every line moving independently

### Rule
사용자가 콘텐츠를 기다려야 할 정도로 느리면 실패.

# 35. 모션 접근성
