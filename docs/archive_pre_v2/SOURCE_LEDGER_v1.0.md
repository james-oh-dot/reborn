# 0. GOVERNING RULES

1. **사용자가 현재 대화에서 직접 제공한 연혁을 최우선 사실원본(L1)으로 취급한다.**
2. 계약서·인증서·특허 등 직접 증빙은 **Primary Evidence(L2)** 로 연결한다.
3. 과거 IR·회사소개서 등 사내 문서는 **Company Archive(L3)** 로 연결한다.
4. 제안서·기획서는 프로젝트 참여 또는 기획의 증거일 수 있으나 완료 실적의 증거로 사용하지 않는다.
5. `CONTRACTED ≠ DELIVERED`, `MOU ≠ COMPLETED`, `PROPOSED ≠ BUILT`, `BETA ≠ COMMERCIAL SERVICE`.
6. 확인되지 않은 완료·공급·운영 상태는 반드시 `TBD / UNVERIFIED`로 남긴다.
7. 종교 관련 프로젝트는 회사 정체성을 규정하는 콘텐츠로 사용하지 않는다.
8. 본 Ledger의 `Website Use`는 콘텐츠 채택 여부가 아니라 **향후 검토 우선순위**다.

# 1. SOURCE AUTHORITY

| Code | Authority | Definition | Use |
|---|---|---|---|
| L1 | USER APPROVED CURRENT FACT | 사용자가 현재 프로젝트에서 직접 제공·정정한 사실 | 최우선 |
| L2 | PRIMARY EVIDENCE | 계약서·인증서·특허·공식 증빙 | 직접 검증 |
| L3 | COMPANY ARCHIVE | IR·회사소개서 등 과거 공식 자료 | 보조 검증 |
| L4 | PROJECT / PROPOSAL MATERIAL | 특정 프로젝트 제안·기획 자료 | 범위·역할 참고 |
| L5 | INFERENCE | 자료를 종합한 해석 | 외부 공개 금지, 승인 필요 |
