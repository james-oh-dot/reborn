# 0. PURPOSE
# 0. 문서 목적

이 문서는 리본소프트 홈페이지에서 **무엇을 어떤 순서와 강도로 말할 것인지**를 정의한다.

This document defines **what Rebornsoft should say, in what order, and at what level of emphasis** across the corporate website.

본 문서는 아직 최종 문장 하나하나를 고정하는 `FINAL COPY DECK`은 아니다.

This is not yet the final line-by-line `COPY DECK`.

# 1. CONTENT GOVERNING PRINCIPLE
# 1. 콘텐츠 운영 원칙

리본소프트의 홈페이지 카피는 회사가 “무엇이라고 주장하는가”보다  
**무엇을 해왔고, 무엇을 만들 수 있고, 무엇으로 증명할 수 있는가**를 먼저 보여준다.

Rebornsoft's copy should prioritize **what the company has built, what it can contribute, and what proves those capabilities**, rather than relying on self-promotional claims.

### Core flow / 핵심 흐름

**IDENTITY**  
우리는 어떤 회사인가

↓

**CAPABILITY**  
무엇을 할 수 있는가

↓

**PROOF**  
무엇이 그것을 증명하는가

↓

**EVOLUTION**  
어떻게 여기까지 발전했는가

↓

**DIRECTION**  
지금 어디로 가고 있는가

↓

**CONTACT**  
왜 지금 대화를 시작해야 하는가
