# 0. VERSION 1.1 — WHAT CHANGED

### New priority logic
**대표 Work = 실제 수행·공급 경험을 먼저 보여준다.**

Project count보다:
- 정확한 역할

- 7 Cubic → **Flagship에서 제외**, Systems & Development History로 이동
- Cityfield → **Completed Work에서 제외**, Contracted Engagement로 이동

- FIT-M / Hana → Institutional / Technology Execution Proof로 강화
- 2025–2026 current project → **Current Work**, 단 Completed Case와 분리
- WORK 페이지를 다층 Evidence Architecture로 확장

# 3. EVIDENCE GRADES
# 3. 증거 등급

# 15. IMAGE GOVERNANCE
# 15. 이미지 운영

### Delivered Work
Use:
- actual project images
- actual product / service UI
- documentary evidence

Never use generated / stock imagery as project evidence.

### Current Work
Representational / approved concept visuals may be used only if:
- clearly treated as planning / current direction
- not implied to be built
- no confidential project identity leaks

### Weak visual evidence
If fact is strong but imagery is weak:
use editorial typography + metadata + documentary proof,
not fake stock.
