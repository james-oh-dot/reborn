# 0. SOURCE-OF-TRUTH RULE

현재 구현의 Canonical Source of Truth는 다음 3개 문서다.

1. `MASTER_FRAMEWORK_v2.0.md`
2. `EVIDENCE_LEDGER_v2.0.md`
3. `CODEX_EXECUTION_SPEC_v2.0.md`

프로젝트 루트의 `AGENTS.md`는 위 세 문서의 우선순위를 Codex에게 지시하는 라우터 역할만 한다.

기존 v1.0 / v1.1 Framework는 삭제하지 않고 `docs/archive_pre_v2/`로 이동한다.
기존 문서는 역사적 의사결정 기록이며 **현재 구현을 지배하지 않는다.**

예외:
- 실제 원본 PDF, 계약서, 이미지, 인증서, 특허 등 Source 자료는 Archive 대상이 아니다.
- 현재 HTML/CSS/JS 구현물은 Archive 대상이 아니다.
- 기존 Visual Direction / Hero 관련 문서는 향후 디자인 Gate의 참고자료로만 보존하며 현재 콘텐츠 해석의 우선권을 갖지 않는다.

# 1. PROJECT GOAL

리본소프트 공식 홈페이지는 다음을 수행해야 한다.

1. 리본소프트를 신뢰할 수 있는 한국 기반 기술회사로 인식시킨다.
2. AI/Computer Vision에서 출발한 기술이 Interaction, Digital Environment, Physical Experience로 확장되어 온 역사를 설명한다.
3. 실제 수행·납품·공동개발·설치·인증·특허 등 객관적 Evidence를 보여준다.
4. 과거 메타버스 회사, 단순 CCTV 회사, 테마파크 전업회사로 오해되지 않게 한다.
5. 현재는 `SCO Noah's Ark Project`와 같은 대규모 국제 Experience Project로 적용 범위가 확장되고 있음을 보여준다.
6. 완료 실적과 계약·MOU·진행 중 프로젝트를 절대로 혼동하지 않는다.
7. 해외 파트너가 사이트만 보고도 회사의 정체성, 역량, 실제 수행 경험, 현재 방향을 이해할 수 있게 한다.
